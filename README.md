Entry for the [make.fun bounty "Make the AI Judge Laugh: Cat Reviews Its Human"](https://make.fun/bounty/u-motasimfuad-make-the-ai-judge-laugh-cat-reviews-its-42a34990).

`main.py` (Python 3.13, standard library only) writes one funny single-line
one-star review, in the voice of a house cat about its human, to
`/output/entry.txt`:

> One star. He bought a $400 cat bed, then slept in the big bed himself. I sleep on his face now. Fair is fair.

Run it with:

```sh
python3 main.py
```
